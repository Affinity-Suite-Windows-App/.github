## 🚀 Introduction
Affinity Suite for Windows is a professional creative toolkit that gathers three disciplines under one roof: pixel-accurate photo editing, clean vector illustration, and structured page publishing. It is designed so a single project can flow from raw image to polished layout without hopping between disconnected programs. Originally built by Serif and now offered through Canva, suite Affinity serves illustrators, photographers, and designers who want a dependable, well-integrated environment for serious creative work.

## ✨ Highlights

### Create and Refine
- **Photo editing** — Retouch, mask, and composite images with layer-based, non-destructive control.
- **Vector illustration** — Draw scalable shapes, curves, and paths for logos, icons, and detailed artwork.
- **Page publishing** — Lay out multi-page documents with precise typography and image handling.

### Work Efficiently
- **Integrated workspace** — Move between photo, vector, and layout tasks in one shared, familiar interface.

## 💻 System Specs
**Minimum**
- OS: Windows 10 64-bit
- Processor: A modern 64-bit processor with SSE4.2 support
- Memory: 4 GB RAM
- Storage: A few gigabytes of free space for installation

**Recommended**
- OS: Windows 11 64-bit
- Processor: A recent multi-core 64-bit processor
- Memory: 16 GB RAM or more
- Storage: An SSD with generous free space for project files
